# Legacy Auto-Processing Modules

This folder contains older auto-processing scripts kept for backward compatibility and historical workflows.

For current XAMS STBC operations, use:

- [`amstrax/auto_processing_new`](../auto_processing_new/README.md)

## Status

- Legacy scripts here are not the primary production path for XAMS dashboard v2.
- They may still be useful for old notebooks/tests and older operational setups.

## Recommendation

- Do not start new operational workflows from this folder.
- Prefer migrating any active operational scripts to `auto_processing_new`.
