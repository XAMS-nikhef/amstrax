# Notes

`XAMS_amstrax_overview.pdf` — explainer of strax + amstrax 3: where every plugin enters the reconstruction stream,
where the settings come from (corrections PROD5), and dedicated pages on the event tables (`events`, `sites`,
`event_peaks`, `peak_context`, `event_cuts`, `event_windows`: what each holds, keys, definitions, corrections, cuts,
all columns), loading, and the old event format of amstrax ≤ 2.2 (`event_basics` … `event_info`) with the map of
every old column to the new tables. Generated from this checkout (plugin names, versions, inputs, files and line
numbers parsed from the source; columns from `st.data_info`; corrections from `amstrax_files`). Needs matplotlib,
reportlab and an importable amstrax (e.g. the `xamssim` env):

```bash
python docs/notes/make_amstrax_note.py            # needs matplotlib and reportlab; amstrax_files next to amstrax
```

Regenerate after a change to the plugins or contexts and commit the PDF and `figures/` with it. A new or removed
plugin stops the script until it gets a place and a description in the script.

`XAMS_event_structure_proposal.pdf` — design record of the event structure (implemented: since amstrax 3.0 the only one, with `events_v2` renamed `events` and the windows `event_windows`; status box on page 1): `events_v2`, `sites`, `event_peaks` and
`peak_context` next to the flat `event_info` (what goes where, measured sizes, how to answer common questions, open
choices). Implemented as optional data types in #367; the old types are unchanged. Generated by:

```bash
python docs/notes/make_event_structure_proposal.py   # needs matplotlib and reportlab
```
